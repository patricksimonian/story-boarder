# Wayfinder map: Storyline App

Label: wayfinder:map

## Destination

A working first version of a local-first web application — simple to run and own, maximally flexible to author in — that the user runs on their own machine to write the storyline for their video game, with the content stored as plain files at a folder of their choosing, in a format they fully own. Reached via decisions the user has approved (feature set, domain model, file format, platform), then built.

## Notes

- **Execution is carried in this map** (overriding wayfinder's plan-only default): once the spec decisions land, build tickets graduate from the fog and are worked here.
- The user (Patrick) is new to the formal *vocabulary* of narrative design, **not** to writing — he's a capable, creative author. Explain terms of art when they first appear, but do **not** scope features down to a "beginner/hobbyist" subset; he has explicitly rejected that framing and wants **maximum flexibility**.
- Standing preferences (kickoff prompt + correction on 2026-08-25):
  - "Simple" means simple to run and own — not a dumbed-down authoring model. Prefer flexible, growable designs.
  - The user must **own the content**: plain, portable files; no cloud accounts, no lock-in.
  - Content stored **locally at a location of the user's choosing**.
  - Platform: Windows 11.
- Skills to consult: `/grilling` and `/domain-modeling` for decision tickets, `/prototype` for UI questions, `/research` for AFK research.
- Research findings live in `.scratch/storyline-app/research/` and are linked from their tickets.
